# punto-rs

Все команды запускай через `make`.

- `make install` подключает git hooks.
- `make format` форматирует код.
- `make lint` запускает быстрые проверки.
- `make test` запускает тесты.
- Перед завершением работы обязателен зелёный `make full-check`.
- Отправляй изменения только через `make push`.

Инструкции конкретных слоёв ищи в их `AGENTS.md` и в `.claude/rules/`.
