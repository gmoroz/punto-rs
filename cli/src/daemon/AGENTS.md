# Захват и переигрывание ввода

`cli/src/daemon/tests.rs` проверяет корректность коррекции без реальных evdev и uinput-устройств через KeyOutput.

- Коррекция начинается только после успешного EVIOCGRAB; ввод до времени захвата прерывает её, ввод после захвата попадает в очередь.
- После снятия захвата переигрывай накопленный ввод и дождись отпускания удерживаемых виртуальной клавиатурой клавиш.
- Отмена, смена сессии, закрытие потока и ошибка вывода не должны оставлять синтетические клавиши нажатыми.
- При изменении этой логики дополняй регрессионные тесты в `cli/src/daemon/tests.rs` для соответствующего порядка событий и временных меток.
